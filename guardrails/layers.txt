# Layer rules (ADR 0038, ADR 0039), checked by crates/oso/tests/architecture.

# Each [section] names a crate, or [workspace] for the graph between crates.
# Inside a section, each line is one layer, highest first. An entry may use
# only entries on lower lines; entries on the same line may not use each
# other. Every crate and every top-level module (`mod name;` in the crate
# root) must be listed. Uses are found in `crate::`, `super::` and, in the
# root, bare paths to child modules; comments and doc links do not count.
#
# `crate` is the crate root (lib.rs or main.rs). Its `mod` declarations and
# `pub use` re-exports are wiring, not uses. If `crate` is not listed, it
# sits above every layer.
